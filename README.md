# ustad - Hello World Python Projesi

Basit bir Python projesi - çalıştırıldığında terminal ekranına "hello" yazdırır.

## Kurulum

Herhangi bir kurulum gerekmez, sadece Python 3 gereklidir.

## Çalıştırma

Terminal'de aşağıdaki komutu çalıştırın:

```bash
python main.py
```

veya:

```bash
python3 main.py
```

## Beklenen Çıktı

```
hello
```
